      Railroad Library

      Import a List

      Paste a list or choose a file. Two layouts work: a CSV with a header row (Railroad Name, Reporting Mark, Type, States, Track Mileage, and so on), or one railroad per line as Name | State | Type of operation, with a region name on its own line above each group. Railroads already in the library only get their blank fields filled in.

      Add Train Type

      Watch Folder

      Use the watch folder to add extra subdivision CSVs in bulk instead of one at a time with Add subdivision. Drop in as many files as you like. While TRAIN LOG is open it checks the folder every few seconds, imports each CSV into the station book, and moves the file into imported/. A file that cannot be read goes into failed/ with a note saying why.

      Each CSV holds one subdivision. Row 1 lists the railroad marks, such as BNSF or UP. Row 2 is Subdivision,Location,Milepost,State; State is an optional two-letter code such as AZ.
